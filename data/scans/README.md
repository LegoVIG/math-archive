# PDF Scans Repository

This directory contains uploaded and starter PDF documents referenced by PDF notes in the Math Archive.

## Files:
- `ceva_menelaus.pdf`: Starter scan for Geometry lecture notes.
- `sample_lecture.pdf`: Starter scan for Mathematical Analysis lecture notes.
- `series_convergence.pdf`: Additional scan for Series Convergence.

PDF files uploaded via the web interface (`POST /api/upload-pdf`) are stored here with sanitized filenames.
