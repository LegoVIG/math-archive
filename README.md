# Интерактивный математический архив (Math Archive)

Единый образовательный портал по 5 фундаментальным разделам олимпиадной и высшей математики:
1. **Комбинаторика** (оранжевая гамма) — полная база: 29 глав, 3 014 олимпиадных задач с ответами, идеями и планами решений, карта курса с интерактивным графом.
2. **Алгебра** (красная гамма) — чистый шаблон для наполнения.
3. **Теория чисел** (синяя гамма) — чистый шаблон для наполнения.
4. **Геометрия** (зеленоватая гамма) — встроенный движок GeoGebra Classic для построения динамических чертежей к задачам.
5. **Матанализ** (фиолетовая гамма) — чистый шаблон для наполнения.

---

## Возможности

- **Автономный SPA без внешних сборщиков**: `index.html` полностью самодостаточен, готов к моментальной публикации на GitHub Pages без `npm`/`webpack`.
- **Единая структура**: `(Темы, Методы, Разделы) -> Параграфы -> Теория и Задачи`.
- **Режим редактирования (`Ctrl + E`)**:
  - Интерактивное перетаскивание (Drag & Drop) вершин графа с пересчётом связей;
  - Редактирование предков и потомков на карте тем;
  - Добавление, редактирование и удаление тем, разделов и задач;
  - Прямое редактирование ответов, идей и планов решения с живым KaTeX-предпросмотром.
- **Встроенная классическая GeoGebra**: полноценное чертёжное полотно для задач геометрии с сохранением чертежей на диск.
- **Двойная синхронизация (Dual-Sync)**: данные атомарно сохраняются на диск через `server.py` и синхронизируются во встроенные теги `<script type="application/json">` для работы офлайн и на GitHub Pages.
- **Строго без эмодзи**: чистая векторная типографика и SVG-пиктограммы.

## Запуск

### 1. Локально с сервером персистентности (рекомендуется)
```powershell
python server.py
```
Открыть в браузере: `http://localhost:8000`

### 2. Офлайн / без сервера
Просто откройте файл `index.html` двойным кликом в любом браузере.

## Публикация на GitHub Pages

1. Инициализируйте Git и опубликуйте репозиторий:
   ```powershell
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-аккаунт>/<имя-репозитория>.git
   git push -u origin main
   ```
2. В настройках репозитория на GitHub перейдите в **Settings -> Pages**.
3. В блоке **Build and deployment** выберите источник **Deploy from a branch**, ветку **main** и папку **`/ (root)`**.
4. Через 1–2 минуты сайт станет доступен по адресу:
   `https://<ваш-аккаунт>.github.io/<имя-репозитория>/`
